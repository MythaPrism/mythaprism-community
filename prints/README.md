# Free sample prints

Print files made in MythaPrism, so you can check that our files print on your printer before you buy anything. Each 3MF opens as a ready project in Bambu Studio, OrcaSlicer and PrusaSlicer, and its PDF lists the filaments and the changes. The file name says which color matcher made it. BW Free files are what the free plan makes.
